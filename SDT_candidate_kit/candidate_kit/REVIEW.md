## Looked at and decided were **not** defects

* `load_dotenv()` (L19): its default is `override=False`, so real environment variables already win over `.env`, as required.
* `IST = timezone(timedelta(hours=5, minutes=30))` (L25): correct, and IST has no DST, so a fixed offset is right.
* Date-range filter in `list_attendance` (L136-141): comparing `"YYYY-MM-DD"` strings with `$gte`/`$lte` is correct because the format is fixed-width and zero-padded, so string order is date order.
* `department` filter is exact and case-sensitive: that is what the contract asks for.
* `max(0, ...)` / `int()` truncation in `compute_overtime`: `int()` truncates toward zero, which equals floor for the non-negative values that matter; kept the idea, but moved to integer seconds `// 60`.
* Plain `def` endpoints with synchronous PyMongo: FastAPI runs them in its thread pool, so they do not block the event loop, and PyMongo's client is thread-safe. Concurrency correctness is enforced by MongoDB (unique indexes, conditional updates), not by Python locks.
* Using `insert_one(doc)` and then returning `doc` (L118): PyMongo adds `_id` to the dict in place, which is why the starter had to pop it; harmless once responses go through a serializer.
